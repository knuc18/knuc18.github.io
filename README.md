# knuc18.github.io

Kevin Nucum's portfolio. Vite + React + TypeScript, with a [Canvas UI](https://canvasui.dev) `HexFloat`
WebGL hero effect and the OPERATOR design system tokens.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` build and deploy automatically via `.github/workflows/deploy.yml`.
